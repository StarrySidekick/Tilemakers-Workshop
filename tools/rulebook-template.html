Soffiando Rulebook

Every rule of the cloud kingdom as the game plays it today, and every tile in its deck. Each rule has a test that plays it on the game's engine, so if a rule here and the game ever disagree, the check fails.

Turn a tile on or off, or change how many copies go in. Your changes wait here until Claude builds them.

Everything you change here is saved as you go. To put it in the game, tell Claude: apply the Soffiando Rulebook. Claude reads it from this page, builds each change with a test that proves it, and it comes back here as part of the rules and the deck.
